---
name: Aggiorna memory dopo git
description: L'utente vuole che i file di memory vengano creati/aggiornati dopo ogni aggiornamento git significativo
type: feedback
---

Dopo ogni commit/push significativo, aggiornare i file di memory del progetto con lo stato corrente.

**Why:** L'utente ha chiesto esplicitamente di tenere traccia delle sessioni e degli aggiornamenti git tramite memory.
**How to apply:** Al termine di ogni sessione con commit, aprire MEMORY.md e i file di progetto rilevanti e aggiornarli con cosa è cambiato e perché.
